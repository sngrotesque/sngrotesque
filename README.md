  `003CC84A9F6B10C233114C18F1E31EE85D9E0244`

- **长密钥 ID (Key ID)**  
  `0xF1E31EE85D9E0244`

你可以通过这些信息获取我的公钥，并验证你下载的文件是否确实由我本人发布。
